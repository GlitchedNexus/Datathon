# Slides Setup

- Theme: Tailwind sky palette (see `styles/colors.yaml`) with Inter typography (`styles/typography.md`).
- Deck layouts to prep in `deck_template.pptx`:
  1. Title + subtitle
  2. Two-column (text + figure)
  3. Full-width figure
- Backgrounds: prefer light with thin sky grid accents; reserve dark neutral (`#0b1120`) for title/impact slides.
- Figure placement: pull final assets from `figs/final/` with descriptive filenames.
- Suggested body text size: 18-20 pt; headings follow typography guide.

The file `deck_template.pptx` is a placeholder; update it in your slide tool with the colors/fonts above before the event.
